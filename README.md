# SteelBattalionControllerTester_CLI
A Controller Tester for the Steel Battalion controller using Libusb-1.0 and NCurses

## Building from Source
#### Dependencies
This tool depends on the libusb-1.0 and ncurses, and building from source requires gcc and make
`sudo pacman -S gcc make libusb-1.0 ncurses`

#### Building
`make`

## Running
`./build/test`
